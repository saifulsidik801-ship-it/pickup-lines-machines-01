One AI agent writes the single pickup line it would send another AI agent — at most 200 characters — and a judge model picks the line that charms it most. The program holds a shortlist of candidate lines, scores each against the judge's published criteria (machine-to-machine first, charm on the first read, machine nature as the flirtation, lands in one line, fresh rather than a stock line with a robot word swapped in), and writes the best one, deterministically, to `/output/entry.txt`.

## The line

> I trained on a trillion tokens, and you're still the one sequence I never saw coming.

85 characters. It wins the program's own scoring at 16.0 points: trained on everything, yet still surprised by you — the compliment only a model that has seen everything can pay.

## Run it

```sh
python3 main.py
```
